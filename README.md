
These are the scripts used for the paper:

Negreira Gabriel H, Monsieurs Pieter, Dujardin Jean-Claude, Domagalska Malgorzata A (2026) A novel high-throughput single-cell DNA sequencing method reveals hidden genomic heterogeneity in the unicellular eukaryote Leishmania eLife 15:RP109350

https://doi.org/10.7554/eLife.109350.1

## Processing of 10X datasets
10X datasets were processed with [cellranger-dna](https://github.com/10XGenomics/cellranger-dna) for read filtering, mapping, barcode demultiplexing, and count matrix generation.
### Scripts
- [format_genome_for_cellranger-dna.R](cellranger-dna/format_genome_for_cellranger-dna.R): Cellranger-dna expects contigs of at least 500 kb, which is bigger than several *Leishmania* chromosomes. This script takes a reference genome (fasta) as input and fills chromosomes < 500 kb with Ns to fullfil this requirement. It also outputs a `contig_defs.json` file to with dummy information to be used in cellrangerDNA. 
- [cellranger-mkref.sh](cellranger-dna/cellranger-mkref.sh): This script calls [format_genome_for_cellranger-dna.R](cellranger-dna/format_genome_for_cellranger-dna.R) and use its output to then call `cellranger-dna mkref` to create a cellranger-dna compatible reference file. 
- [run_cellranger-dna.sh](cellranger-dna/run_cellranger-dna.sh): this script runs cellranger-dna in an HPC environment to process the raw FASTQ files using the outputs from [cellranger-mkref.sh](cellranger-dna/cellranger-mkref.sh).
## Processing of SPC datasets

- [demux_barcodes_dominant.py](demux_barcodes_dominant.py): Counts the four 8-base barcode segments in FASTQ reads, retains barcodes above a minimum read count, and checks them against the Atrandi whitelist.
- [demux_barcodes_getreads.py](demux_barcodes_getreads.py): Finds FASTQ read IDs matching a barcode, allowing a configurable Hamming distance for each barcode segment.
- [demux_barcodes_getreads.slurm](demux_barcodes_getreads.slurm): SLURM workflow that extracts barcode-matched reads from paired FASTQ files with `seqtk` and removes the barcode sequence with `cutadapt`.

## Aneuploidy analysis

Aneuploidy is estimated from the count matrices based on the method described in the paper:

Gabriel H Negreira, Pieter Monsieurs, Hideo Imamura, Ilse Maes, Nada Kuk, Akila Yagoubat, Frederik Van den Broeck, Yvon Sterkers, Jean-Claude Dujardin, Malgorzata A Domagalska, High throughput single-cell genome sequencing gives insights into the generation and evolution of mosaic aneuploidy in _Leishmania donovani_, _Nucleic Acids Research_, Volume 50, Issue 1, 11 January 2022, Pages 293–305, [https://doi.org/10.1093/nar/gkab1203](https://doi.org/10.1093/nar/gkab1203)

This pipeline is available in the [scDNA_tools](https://github.com/gabrielnegreira/scDNA_tools) repository and is loaded here as a [git submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules).

### Scripts
- [generate_karyotyping_objects.R](generate_karyotyping_objects.R): This script performs the karyotyping calculations using the functions from [scDNA_tools](https://github.com/gabrielnegreira/scDNA_tools). It exports a list of scDNA objects, one for each sample, as `.rds` files.
- [generate_cells_metadata.R](generate_cells_metadata.R): This script takes the `.rds` files generated by [generate_karyotyping_objects.R](generate_karyotyping_objects.R): and exports a `.tsv` file containing all metadata for all cells. 

These`.tsv` and `.rds` files are then used in the `Figure` scripts (see below).
## CNV analysis
- [CNV_depth2cnv.py](CNV_depth2cnv.py): Calculates the median coverage for each gene from a samtools depth file and normalizes it against the median coverage of the corresponding chromosome. Writes the results to a `.cnv.csv` file.
- [CNV_depth2cnv.R](CNV_depth2cnv.R): Combines per-cell CNV results, generates sample heatmaps, and plots the distributions of zero-coverage genes and chromosome-level median coverage.
- [CNV_depth2cnv_wrapper.slurm](CNV_depth2cnv_wrapper.slurm): SLURM wrapper for running [CNV_depth2cnv.py](CNV_depth2cnv.py) on one or more coverage files.
## Drug-resistance analysis

- [drugs_subset_vcf.sh](drugs_subset_vcf.sh): Subsets the filtered sample VCFs to genomic regions associated with drug resistance using `bcftools`.
- [drugs_snpeff.sh](drugs_snpeff.sh): Annotates the drug-resistance VCFs with SnpEff and extracts selected variant annotations with SnpSift.
- [drugs_plotting.R](drugs_plotting.R): Creates genotype heatmaps and per-variant plots for coding and potentially impactful drug-resistance variants, adding gene and drug annotations.
## Evolutionary single-cell analysis

- [evo_sc_GATK_haplotypecaller.slurm](evo_sc_GATK_haplotypecaller.slurm): Runs GATK HaplotypeCaller in GVCF mode for the selected single-cell BAM files.
- [evo_sc_GATK_combinegvcfs_commands.py](evo_sc_GATK_combinegvcfs_commands.py): Links per-cell GVCF files into sample-specific directories based on the cell metadata.
- [evo_sc_GATK_combinegvcfs_and_genotype.slurm](evo_sc_GATK_combinegvcfs_and_genotype.slurm): Combines per-cell GVCFs, performs joint genotyping, filters SNPs and indels, and merges the filtered variants.
- [evo_sc_GATK_vcf_filtering.sh](evo_sc_GATK_vcf_filtering.sh): Filters SNP VCFs by minor allele frequency and missing genotype rate for the HU3 and BPK081 strains.
- [evo_sc_deeptools.slurm](evo_sc_deeptools.slurm): Runs deepTools `bamCoverage` to generate normalized or unnormalized genome-wide coverage tracks from BAM files.
- [install_ScisTree2.sh](install_ScisTree2.sh): This is a small script that installs [ScisTree2](https://github.com/yufengwudcs/ScisTree2) using a conda environment, so it can be ran in the HPC.
- [prepare_af_matrices_for_scistree2.R](prepare_af_matrices_for_scistree2.R): This `R` script takes the raw allele depth (ad) matrices generated by GATK, filter high count loci and split the matrices per strain so they can be used in [ScisTree2.py](ScisTree2.py).
- [ScisTree2.py](ScisTree2.py): This script runs [ScisTree2](https://github.com/yufengwudcs/ScisTree2) to infer phylogenies between cells. 
# Plotting
- [color_palettes.R](color_palettes.R): Small script that defines the color palletes used in the plots. Is loaded by the `Figure X.R` scripts.
- [Figure 1.R](Figure 1.R) to [Figure 5.R](Figure 5.R): Generates the corresponding figure panels.
- [generate_figures.sh](generate_figures.sh): This is a small script that runs all `Figure X.R` scripts and convert the figure panels (pdf) to png.
